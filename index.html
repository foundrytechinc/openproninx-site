FNU / OpenProninx

OpenProninx is an open-source operating system for the x86_64 architecture (MBR and UEFI) licensed under BSD-3-Clause; it is based on PRONINX, which in turn was based on xv6.

This project aims to be self-contained: it features its own kernel, bootloader, and the majority of the user environment. Drivers are the exception.

Development software. The current baseline is Core 0.1.6-dev. It is not production-ready and must not be exposed to an untrusted network or used for confidential data.
