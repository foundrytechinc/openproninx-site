OpenProninx Handbook

This handbook describes FNU/OpenProninx Core 0.1.8-dev as implemented in the source tree (inc/product.h): architecture, build and run workflow, system-call ABI, kernel subsystems, storage, networking, init and services, and the FNU userspace. Facts below follow the code; the older prose under doc/ may lag behind.

Development baseline. Core 0.1.8-dev is not production-ready. Do not expose it to an untrusted network or store confidential data on it. Default credentials are for throwaway images only - change them.

What is OpenProninx?

OpenProninx is a free, independent x86-64 operating system under the BSD 3-Clause License, developed by Foundry Technologies (originally as PRONINX, once based on the xv6 x86_64 port). It is no longer an educational xv6 fork: it has its own kernel, boot path (BIOS and UEFI), drivers, storage, networking, graphics, and userspace.

FNU (Foundry Not Unix) is the userspace written for it - init, the supervisor fnusvc, shell, utilities, libraries (libc, libfnu, libm, libcrypt, libutil, libssh). FNU is not a GNU replacement, not a compatibility layer, and not an OS by itself. No component is under GPL/LGPL.

Build and run

Host requirements:

  • bmake (BSD make)
  • clang, lld, LLVM binutils (llvm-ar, llvm-objcopy, ...)
  • makefs with FFS/UFS2 support (FreeBSD/NetBSD port; without it the root partition stays empty and a ramdisk is used)
  • QEMU (qemu-system-x86_64) for bmake qemu; OVMF for UEFI
  • Optional: clang-format, lldb/gdb, host yacc for awk

Common targets (from the top-level Makefile):

bmake              # default: obj/PRONINX.img + obj/fs.img
bmake -j$(nproc)   # parallel build
bmake ci           # build, assert images non-empty, smoke test
bmake qemu         # BIOS boot, virtio-vga, e1000 user net, serial mon:stdio
bmake qemu-uefi    # same image under UEFI (OVMF)
bmake smoke        # tools/smoke-qemu.sh: boot, login, FS torture, shutdown
bmake qemu-debug   # QEMU paused with GDB stub on tcp::12345
bmake lldb         # attach lldb to that stub
bmake font SPLEEN=<dir>   # rebuild kern/font_spleen.c from Spleen BDF
bmake format       # clang-format on boot/ kern/ inc/ lib/ user/
bmake clean        # remove obj/, .gdbinit, qemu.log, generated vectors.S

QEMU knobs: CPUS=2 (default SMP), VBE_WIDTH / VBE_HEIGHT to force a framebuffer size, QEMU_EXTRA_OPTS= for extra devices.

Image write to USB (destructive to the target device): dd if=obj/PRONINX.img of=/dev/sdX bs=4M conv=fsync. The same hybrid GPT image boots from BIOS and from UEFI.

Accounts and first boot

  • Shipped accounts in /etc/master.passwd: root, daemon, nobody (bcrypt hashes).
  • README: default root password root.
  • Build embeds /etc/firstboot: once, it runs useradd -m -G wheel ... admin with a baked hash (README: password admin). That account is in wheel so doas works.
  • Account tools: useradd (alias adduser), usermod, userdel, groupadd, chpass (chsh/chfn). Defaults live in /etc/users.conf.
  • Setuid programs: login, passwd, su, doas, ping, chpass. /etc/doas.conf permits group wheel.

Init, services, shutdown

init (pid 1, user/init.c) is a small BSD-style state machine. It starts the supervisor /usr/bin/fnusvc, which reads one file per service from /etc/rc.d. Ordering ideas come from illumos SMF and FreeBSD rcorder.

/etc/init.conf keys read by init: start= (single | boot | multi, default multi), console= (insecure asks for the root password in single user), shutdown_timeout= (default 90 seconds), trace=.

States include single user, boot shell, multi user, clean shutdown, reboot, halt, poweroff. Boot-stage services (from rc.conf / rc.d): fsck, root, sysctl, hostname, mountall, swap, tmp, var, dmesg, firstboot, then multi-user: syslogd, powerd, fnuplug, sshd, moused, consolemouse, and login on tty1..tty4 plus serial loginu0.

Service files: one name=value per line (desc=, stage=, run= / step=, stop=, requires= / before= / provides=, restart=, limit=, user=, dir=, env=, log=, timeout=, on=, secure=). Enable with services enable / disable. States: waiting, starting, running, done, failed, maintenance, stopping, stopped, absent, blocked. Shutdown: reverse order, SIGTERM or stop=, then SIGKILL; init gives the supervisor shutdown_timeout seconds.

System-call ABI

Entry is software interrupt int $0x30 (T_SYSCALL in kern/trap.h). Number in %rax; arguments in %rdi %rsi %rdx %rcx %r8 %r9. On success: carry clear, result in %rax. On failure: carry set, %rax is an FNU_ERR_* code (no errno in the kernel ABI). libfnu stubs (lib/libfnu/usys.S) negate the error for the caller. Unknown numbers return FNU_ERR_NOCALL.

Numbers: inc/syscall.h (NSYSCALL 128 slots; 98 are assigned). Signatures: inc/fnu.h. Structures and constants: inc/abi.h, open.h, stat.h, signal.h, dirent.h, error.h. POSIX sits on top in libc; tests/fnuonly.c links with libfnu alone. Path calls are relative to a dirfd or FNU_FD_CWD; a null path means the fd itself (so fnu_getattr(fd, 0, 0, &st) is fstat). pledge filters by promise bits (kern/pledge.c).

Full system-call table

Numbers from inc/syscall.h, signatures from inc/fnu.h. All paths: 98 assigned calls, 128 slots (NSYSCALL); unlisted numbers are unused. Userspace name is fnu_*; libc may wrap these as POSIX.

Kernel overview

Boot order in kern/main.c (kmain):

  1. Serial, IRQ PIC, bootinfo, page tables, NX, low memory, message buffer
  2. VFS/devfs, real-mode helpers, framebuffer, console, delay/uptime, EFI RT
  3. ACPI init, clocks, SMP (mpinit), LAPIC, GDT/IDT
  4. Heap, sysctl, scheduler, sockets, SMBIOS, I/O APIC
  5. Random, UVM, futex, hotplug, partitions, net init
  6. Processes, files, pipes, events, UFS2, ramdisk, start APs
  7. Buffer cache, ACPI start, mouse, driver framework + all drivers + PCI scan
  8. create_init, softclock, taskq, netisr, ACPI thread, console refresh, USB explore, bio syncer, UFS2 logger, pagedaemon

SMP and scheduler

  • APs from MADT (or MP table): trampoline below 1 MB, INIT/SIPI, long mode, mp_startup().
  • Failed AP after 5 s is skipped with a diagnostic; S3 wake restarts APs.
  • Scheduler follows DragonFly usched_dfly: per-CPU run queues, nice + estcpu priorities, load-based wakeup, 100 ms RR interval tunable kern.sched.rrinterval.
  • Per-CPU cpu_info at %gs:0; idle via MWAIT/hlt; TLB shootdown IPI; panic stops other CPUs and reboots after kern.panic_reboot_wait_time (default 15 s).

Memory

  • Higher-half kernel; direct map, I/O map for MMIO (ioremap / ioremap_wc).
  • User map/unmap/protect (W^X), memsync, memuse.
  • Kernel: page allocator, kheap with reclaimer thread, contig pools.

Processes, signals, security knobs

  • fork/exec (static ELF), wait with exit info, sessions/process groups, ident (ruid/euid/...), nice, rlimits, timers, ptrace (BSD-style).
  • 64-bit signal masks, altstack, trampoline sigreturn.
  • Threads + futex; ready/events (kqueue-like filters).
  • pledge and unveil (OpenBSD-style) enforced in kern/pledge.c / kern/unveil.c.
  • sysctl tree for tunables; sendsyslog to syslogd.

Driver framework

Defined in kern/driver.h / driver.c: drivers register with probe/attach/detach/intr/poll. PCI scan 0-255 buses; 64-bit BAR decode; MMIO via ioremap; IRQs through IOAPIC; driver_shutdown_all() before poweroff.

Registered at boot (kern/main.c):

  • Net: Intel E1000 (em0), Realtek (re0), VirtIO-Net (vtnet0)
  • Storage: PCI IDE, AHCI, NVMe
  • Display: virtio-gpu (+ VBE/framebuffer console)
  • USB: xHCI, EHCI; hub, HID, UKBD, UMS, mass storage, audio; firmware takeover before attach
  • Input: PS/2 kbd/mouse (atkbd, psm), sysmouse

Networking

  • Stack: lwIP 2.2.1 (third_party/lwip + kern/net/lwip/), NO_SYS + netlock, netisr for loopback.
  • DHCP, ARP, IPv4, ICMP, UDP, TCP; DNS and ping helpers in userspace (resolve, ping, fnu_resolve).
  • Drivers: e1000 (FreeBSD-compatible ID set), re (RTL81xx/8168), virtio-net legacy PCI.
  • Sockets are file descriptors: socket… sockopt_get; domains FNU_NET_INET / FNU_NET_LOCAL. Raw ICMP needs root; setuid ping drops privs after open.
  • Userspace: netinfo, netconfig, netecho, ping, resolve, ssh, sshd, ssh-keygen.
  • SSH-2 client/server in user/ssh/ (OpenBSD crypto: curve25519, ed25519, chacha20-poly1305); host key on first start; no agent forwarding, no scp yet.

Console, video, input

  • Framebuffer console, four VTs /dev/tty1..tty4, FreeBSD teken (xterm/UTF-8). Serial ttyu0..ttyu3; ptys via /dev/ptm.
  • BIOS VBE + EDID; UEFI GOP; coreboot table; virtio-gpu blits. Fallback VGA text at 0xb8000.
  • Fonts: Spleen 2.2.0 (8x16, 12x24, 16x32, 32x64) including Cyrillic; rebuilt with bmake font SPLEEN=....
  • Keyboard: FreeBSD kbd/atkbd tables, USB HID keyboards, keymaps under /usr/share/vt/keymaps/, kbdcontrol. Alt-F1..F4 switch VTs; Ctrl-Alt-Del to init.
  • Mouse: moused + console pointer; PS/2 and USB; /dev/sysmouse.
  • Video mode switch: vidcontrol; real-mode Video BIOS via x86emu for BIOS/S3 paths.

ACPI, power, TPM

  • kern/acpi/: RSDP/FADT/MADT/DSDT, AML interpreter, GPE/SCI thread, device match by HID/CID.
  • Drivers: EC, buttons/lid, AC, battery, thermal, PCI routing, CPU P-states, backlight, TPM.
  • Sleep S3 / hibernate S4 with LZ4 image; wake trampoline; optional idle sleep.
  • TPM 1.2/2.0 (CRB/TIS), entropy harvest, /dev/tpm0 root-only.
  • powerd picks CPU frequency; sysctls hw.cpu.*, hw.acpi.*, hw.sensors.*.

FNU userspace

  • PRONINX Shell: the system shell is called PRONINX Shell. On disk and in the tree it is simply sh (user/sh, FreeBSD Almquist / ash lineage) with job control and builtins - but the product name is PRONINX Shell.
  • Editors: vi (neatvi lineage), ed, patch.
  • Text: grep, sed, awk, diff, sort, tr, cut, head/tail, ...
  • File: ls, cp/mv/rm, find, mount, pax (tar/cpio), ...
  • System: ps, top, sysctl, dmesg, init, fnusvc, services, doas, login, sshd, fnufetch, fnudate, fnuman (man), ...
  • Libraries: libc (POSIX + more), libfnu (raw ABI + tables/resolve), libm, libcrypt, libutil, libssh crypto.

Tests and CI

  • tests/: process, VM, FD, pipe, pthread/futex, event, socket, inet, FS torture, hibernate, pledge/unveil, pty, SSH, etc.
  • In-guest: /usr/tests/run (or named tests).
  • Host: bmake smoke / bmake ci.
  • GitHub Actions (.github/workflows/build.yml): install toolchain, build makefs, bmake ci, upload obj/*.img and staged root; separate job builds UFS2 root under FreeBSD and runs fsck_ffs -n.

Security status

  • Baseline 0.1.8-dev is a development image: no verified boot, no signed updates, no privilege separation in sshd, no encrypted root, no full audit trail.
  • Present building blocks: pledge/unveil, wheel/doas, bcrypt accounts, setuid discipline, raw sockets restricted, fnusvc FIFO root-only, klog restricted to root/wheel.
  • sshd may accept passwords (including root) and has no privsep - stop it on untrusted networks.
  • Report vulnerabilities privately (see SECURITY.md in the source repo), not in public issues, until a dedicated policy is published.
